# Studi Kasus: Landing Page Produk HEARTCALM Acne Water Gel

## A. Petunjuk:
1. Baca dan pelajari setiap instruksi kerja di bawah ini sebelum melaksanakan praktik.
2. Klarifikasi kepada Asesor apabila terdapat instruksi yang belum jelas.
3. Laksanakan pekerjaan sesuai urutan proses dan demonstrasikan hasil website.
4. Seluruh proses kerja mengikuti SOP/WI yang dipersyaratkan dan dapat dibuktikan melalui source code serta
website yang berjalan.

## B. Skenario:
Anda berperan sebagai Junior Web Developer yang diminta mengembangkan sebuah landing page untuk produk
perawatan kulit HEARTCALM Acne Water Gel. Website harus menyajikan informasi produk secara jelas,
responsif, memiliki navigasi dan komponen interaktif, serta dapat diakses secara daring. Gunakan HTML, CSS,
JavaScript, dan library yang dikuasai. Pada asesmen, demonstrasikan implementasi, struktur kode, dan pengujian
fungsi yang telah dibuat.

## C. Langkah Kerja:
Buat atau demonstrasikan website dengan ketentuan sebagai berikut:
1. Identitas dan teknologi website
– Website berupa landing page satu halaman bertema HEARTCALM Acne Water Gel,
– Gunakan HTML untuk struktur halaman, CSS untuk tampilan, dan JavaScript untuk interaksi; dapat
menggunakan Bootstrap dan Bootstrap Icons.
2. Antarmuka dan konten produk
– Tampilkan hero section yang memuat nama produk, deskripsi singkat, ilustrasi/foto produk, serta tombol “Beli
Sekarang” dan “Konsultasi Admin”.
– Sediakan navigasi menuju bagian Bahan, Manfaat, Permasalahan, Hasil Penggunaan, dan Testimoni.
– Tampilkan informasi bahan utama, manfaat produk, permasalahan kulit, contoh hasil penggunaan, serta
testimoni dalam tata letak yang mudah dibaca.
3. Komponen interaktif
– Implementasikan accordion untuk menampilkan daftar bahan tambahan.
– Implementasikan carousel/slider untuk bagian permasalahan kulit.
– Implementasikan navigasi antarbagiannya (smooth scrolling) dengan penyesuaian posisi terhadap navbar.
– Sediakan formulir newsletter dengan pemeriksaan format email dan pesan/modal konfirmasi ketika input valid.
Konfirmasi tersebut merupakan simulasi antarmuka, bukan bukti penyimpanan email ke database.
4. Tautan dan responsivitas
– Pasang tautan CTA menuju kanal pembelian eksternal dan kanal kontak yang disediakan.
– Pastikan layout, menu navigasi, kartu informasi, gambar, dan formulir dapat digunakan pada layar desktop
maupun ponsel.
5. Organisasi sumber daya dan kualitas kode
– Susun file secara rapi, misalnya index.html, folder css/, js/, asset/, dan library/.
– Gunakan penamaan variabel/fungsi yang mudah dipahami, struktur HTML yang logis, dan pemisahan kode
sesuai fungsinya.
– Demonstrasikan penggunaan komponen/library siap pakai, misalnya Bootstrap untuk navbar, accordion,
carousel, modal, dan form validation.
6. Uji fungsi dan penayangan
– Uji tautan menu, accordion, carousel, tombol CTA, dan validasi newsletter dengan input email valid dan tidak
valid.
– Tunjukkan hasil tampilan pada minimal satu layar desktop dan satu layar ponsel.
– Jalankan website melalui browser dan tunjukkan URL publik beserta source code proyek.
